# Open questions

Numbered so the format pages and [`STATUS.md`](STATUS.md) can point at them. Each is something not yet known about the original game files or rules. When one is answered, its page is updated and the entry says so. Each question links its detailed note in [unknowns/](unknowns).

For debugger procedures that use the original game, see [Needs a running game](NEEDS_A_RUNNING_GAME.md).

Decorations stay YVEL1 | [formats/vcn_vmp.md](formats/vcn_vmp.md), [unknowns/04_yvel2.md](unknowns/04_yvel2.md) |

| Q6 | The full TIM opcode table. **Answered.** The 139 CD scripts and the floppy intro/outro are counted; 0x07 in game and nested 0x02 are native return-1 stubs in both editions; the floppy intro tables are resolved. The extra words of nested 0x07 and 0x0D are format arguments: the formatter at CD `MAIN.EXE+0x1705E` reads `operand[index]` once per `%n`, `%s`, `%d`, `%u`, `%x` or `%X` ([unknowns/06](unknowns/06_tim_opcodes.md)). Nested 0x03 does not pass its fourth word | [formats/tim.md](formats/tim.md) |
| Q7 | Game rules as formulas. **Mostly answered** ([game_rules.md](game_rules.md), [unknowns/07_native_rules.md](unknowns/07_native_rules.md)): combat arithmetic, spell dispatch (Vortex has no effect in either edition), the 12 timers with their periods, regeneration, lamp oil, monster mode flags and the WLL dispatch are traced in both executables. | Q8 | What script function 0x7E did. **Answered** ([unknowns/08_native_script_exit.md](unknowns/08_native_script_exit.md)): it exits the game to DOS (shutdown preparation, then INT 21h AH=4Ch with status 0); called from level 2's script. A CD launch of `MAIN.EXE` with no argument takes the refusal at `+0x51F00` (English, no music, no effects, no digitized sound), enters the prep with `DS:3618` and `DS:361E` clear, and does not call the optional callback or the video query. A quit from play on the English CD with Sound Blaster is traced too: `DS:361E` was null, the saved BIOS mode was restored and the exit status was 0 ([answered probe](NEEDS_A_RUNNING_GAME.md#q8-which-shutdown-callbacks-run-on-a-given-installation)). Open: whether any setup registers a nonzero callback | [formats/emc2.md](formats/emc2.md), [running-game test](NEEDS_A_RUNNING_GAME.md#q8-which-shutdown-callbacks-run-on-a-given-installation) |
| Q9 | Which PAK wins when two PAKs hold the same member name. **Answered** ([unknowns/09_pak_order.md](unknowns/09_pak_order.md)): a loose file beats every PAK; an earlier-loaded archive beats a later one; inside one archive the later entry wins. The 81 game archives share no member names; only the prologue archives collide. | [formats/pak.md](formats/pak.md) |
| Q10 | Who plays the 59 `NNNNN.VOC` members of the CD speech files. **Mostly answered** ([unknowns/10_nnnnn_voc.md](unknowns/10_nnnnn_voc.md)): all 59 are one identical `00000.VOC` clip, the first and last entry of each TLK; no script or speech builder asks for it. `ENG/FINALE.EXE+0x1D1D0` is a catalog row for that name (size 44115); no instruction names row 40 or its name; the lookup at `+0xCDD1` takes its index from a run-time table (`0x1B41:0`, zero in the file). Running-game test parked (not run): [test](NEEDS_A_RUNNING_GAME.md#parked-probes-not-run). | [formats/tlk.md](formats/tlk.md) |
