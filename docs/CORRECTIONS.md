# Corrections

This page lists what these pages got wrong, how it was caught, and the commit that fixed it. Entries name roles, not people or tools: the writer wrote the work, the reviewer re-derived it before merge, the lead planned, reviewed it again and pushed it, and the owner decides. New entries are added whenever a published statement is corrected.

Dates are commit dates. A commit link opens the change on GitHub.

## Published, then corrected

Newest first. Each statement below was on GitHub before it was corrected.

- **2026-11-20.** The level sheets and the level-sheet guide called script event `0x0800` "monster leaves" the block. The original program raises it for the block a monster enters: after storing the new block at `MAIN.EXE+0x11673` it compares it with the old one and, if they differ, pushes `0x0800` with the new block (`+0x11711`–`0x11735`, CD). The label came from the writer's tool and had passed review. A running-game probe that saw the mode setter run when a monster stepped onto its block led the reviewer to re-read the code. Fixed in the commit that added this entry; levels 23 and 29 and the guide changed.
- **2026-11-20.** The driver page said both editions have one `DRIVERS.PAK` ([`c9d64de`](https://github.com/KForestland/lands-of-lore-1-re/commit/c9d64de031c0b20a97d13d8b2a0941d2926f3f9d), 18 November), and the new driver tool rejected the other one. The CD has a second `DRIVERS.PAK` in its language folders (146 entries; four `.ADV` files differ from the root and floppy copies). The 18 November review passed the statement. The reviewer caught it while merging the driver-table work. Fixed in [`8adfb12`](https://github.com/KForestland/lands-of-lore-1-re/commit/8adfb12121972fe55df24f38bad78035d1171fec).

Fixed in [`9b89cd8`](https://github.com/KForestland/lands-of-lore-1-re/commit/9b89cd8a9273792b406f94c4f36800014533b70e) and [`c2e3a0e`](https://github.com/KForestland/lands-of-lore-1-re/commit/c2e3a0ef7a9024db869b69e5c9353f852312c590) (199 of 199 files).
