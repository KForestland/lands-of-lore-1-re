# What's new

Newest first. One line per answered question, new tool or visible change. Details are on the linked pages; the counts are in the [rating](../README.md#rating).

## 19 November 2026

- **Counted rating.** The README and [STATUS](STATUS.md) show four counted lines instead of a percentage; [how we rate](HOW_WE_RATE.md) explains them.
- **Example pictures remade.** The guard is drawn in its real colours, the talking head in its backdrop's palette, and level 1 as a readable map; a check now compares each example with today's tools pixel for pixel ([examples](../examples/README.md)).
- **Quitting the game (Q8).** The shutdown when quitting from play on the English CD is traced and re-read in the program.
- **Monster fields (Q7, Q18).** Both editions' programs were scanned for every reference to the monster skill and modifier fields ([native records](unknowns/18_native_records.md)).
- **Unused clip and palettes (Q10, Q14).** The finale program's file catalog names the silent speech clip; the three unused palettes have no caller in any program or the installer.
- **New checks:** `rating.py`, `example_images.py`, `lol1_name_callers.py`; `shp_renderer.py --level` draws monster shapes in their level's palette.

## 18 November 2026

- **Running-game results.** The working CD launch, the level-1 wall flags and three save bytes were observed in the original game ([NEEDS_A_RUNNING_GAME](NEEDS_A_RUNNING_GAME.md)).
- **Game rules (Q7) and many open questions answered** from both original programs: the 60 Hz clock, monster modes, the AdLib music layout, the C55 music set and more ([open questions](OPEN_QUESTIONS.md)).
- **Guides.** [Start here](START_HERE.md), [how the game works](HOW_THE_GAME_WORKS.md), a [quick reference](QUICK_REFERENCE.md) and a [worked example](tutorial-one-event.md).
- **Level sheets** for all 29 levels, and XMIDI and AdLib music converted to standard MIDI.
